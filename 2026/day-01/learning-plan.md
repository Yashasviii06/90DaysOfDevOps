# 🚀 My 90-Day DevOps Mission

> "Tools change. Discipline doesn't." — Day 01 of #90DaysOfDevOps

## 1. Where I Stand Today (Current Level)
**Fresher.** I know basic Linux commands, programming logic, and Git (`add`, `commit`, `push`).
My knowledge of Cloud, Docker, CI/CD, and Kubernetes is **zero** right now. These 90 days exist to fix that.

## 2. DevOps and Cloud in My Own Words
- **DevOps** = a way to deliver software *quickly, safely, and repeatedly*. Think of a relay race: Dev passes the baton, Ops carries it forward, and automation keeps every handover smooth.
- **Cloud** = instead of installing your own generator, you take an electricity connection. You don't buy servers, you just use them and pay for what you use.

## 3. Why I'm Doing This
I don't want to be someone who only reads theory. I want to become an engineer who **builds, deploys, and fixes** real systems.
My GitHub should speak louder than my resume.

## 4. My 3 Goals for 90 Days (each with proof)
| # | Goal | Proof |
|---|------|-------|
| 1 | Package an app with **Docker** and run it live on a cloud VM | Public URL + Dockerfile |
| 2 | Build a **CI/CD pipeline**: push → test → build → deploy | Green GitHub Actions run |
| 3 | Deploy the app on **Kubernetes**, then read logs and debug it | Manifests + `kubectl` screenshots |

## 5. My 3 Core Skills
1. **Linux troubleshooting**: logs, processes, permissions, networking
2. **CI/CD + Containers**: Git workflow, pipelines, Docker
3. **Cloud + Kubernetes basics**: AWS fundamentals, pods, services, debugging

## 6. Weekly Time Budget
| Day | Time | Split |
|-----|------|-------|
| Mon–Fri | 2 hours | 45 min theory, 60 min practice, 15 min notes + commit |
| Sat–Sun | 4 hours | Mini-project, revision, LinkedIn post |
| Worst day | **30 min** | The streak must not break |

## 7. My Consistency System (rules, not willpower)
- ✅ Every day: **1 commit + a 3-line note**
- ✅ Every Sunday: weekly review (what worked, what got stuck, next plan)
- ✅ The 2-day rule: never skip two days in a row
- ✅ Learn in Public: share progress on LinkedIn
- ✅ If I'm stuck, I give a topic at most 2 days, then ask for help and move on

## 8. Day-90 Checkpoint
On Day 90, I want to say: **"I built this app, I wrote this pipeline, and when it broke, I fixed it."**
